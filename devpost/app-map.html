Component Flow & Data Journey

File Navigation Index

  • src/App.tsx: The single source of truth. Owns the active plan state, handles navigation transitions, connects actions to storage, and controls the deletion confirmation modal.
  • src/data/templates.ts: Holds the 5 domain template banks (Career, Study, Skill Building, Personal Project, Other). Returns seven structured daily tasks when given a category.
  • src/utils/storage.ts: Manages reading and writing to browser localStorage. Includes strict schema validation so corrupted data won't crash the UI.
  • src/components/TaskCard.tsx: Handles both view mode and inline editing mode with Save and Cancel safeguards. Emits changes cleanly back to App.tsx.
  • src/components/ProgressSummary.tsx: Computes the exact percentage and completed count dynamically with accessible ARIA progress bar tags.
  • src/components/ConfirmModal.tsx: Traps focus and listens for the Escape key to prevent accidental plan deletion.
The Big Practice to Reuse: Plan-First Development

By completing the Scope, PRD, and Technical Specification before touching application code, every single file and interaction had a clear boundary. When unexpected TypeScript warnings arose, we knew exactly which component was affected and resolved it immediately.

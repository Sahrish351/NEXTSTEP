Architecture of User Surfaces

Functional Requirements Matrix

FR-01 Landing Page & Hero

Clean editorial presentation with working CTA that smoothly scrolls down to the creation form.

FR-02 Goal Input Validation

Rejects empty or whitespace-only goals, trims extra spaces, enforces friendly character length limits.

FR-03 Category Selector

Study, Career, Skill Building, Personal Project, Other. Accessible with full keyboard support.

FR-04 7-Day Plan Generation

Produces exactly seven logical starter tasks tailored to category and goal as editable suggestions.

FR-05 Inline Task Editing

Direct inline title and description editing. Save checks non-empty; Cancel cleanly restores prior content.

FR-06 Completion & Accurate Progress

Two-way checkmarks update active progress bar and percentage (e.g. 2 of 7 completed • 29%).

FR-07 Browser Persistence

Saves state in localStorage. Returning or refreshing lands directly in the active workspace.

FR-08 Safe Deletion & Empty State

Modal confirmation dialog protects against accidental deletion and cleanly restores empty state.

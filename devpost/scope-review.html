The Proof of Concept Boundary

  • Homepage & CTA: Clean landing section with working plan creator flow.
  • Goal & Categories: Validated goal input with 5 categories (Study, Career, Skill Building, Personal Project, Other).
  • 7-Day Sequential Tasks: Generates exactly 7 logical, progressive daily tasks tailored to the category and goal, clearly framed as editable suggestions without false guarantees.
  • Task Editing: Inline title and description editing with Save & Cancel safety.
  • Completion Toggling: Two-way checkmarks with clear visual feedback not dependent solely on color.
  • Accurate Dynamic Progress: Real-time calculated progress percentage and counter (e.g. "2 of 7 completed (29%)").
  • Local Persistence: Safe browser localStorage with refresh recovery and corrupted data protection.
  • Safe Deletion & Empty State: Plan reset requiring confirmation dialog and inviting empty state.

Explicitly Out of Scope (Cuts)

User Accounts & Authentication
Friction-free proof of concept; local browser storage is immediate, private, and zero setup.
Cloud Databases & Backend Server
Adds latency, server hosting costs, and complexity without enhancing the core user experience.
Paid AI Generation API
Transparent, editable starter templates are fast, reliable, zero-cost, and honest.
Fake Metrics & Fabricated Testimonials
Maintains product integrity and honesty in hackathon evaluation.

# Project Brief — NextStep

## One-sentence concept
NextStep helps students, job seekers, and busy people turn one real-world goal into seven manageable actions and track their progress.

## Real-world problem
People often have meaningful goals—preparing for a job interview, planning an exam revision week, learning a practical skill, or organizing a personal project—but struggle to decide what to do first. Generic to-do lists do not help them turn a broad goal into a first-week plan.

## Target users
- Students planning a study week.
- Job seekers preparing for interviews or applications.
- Beginners learning a skill.
- People organizing a personal project.

## Core experience
1. A calm, visually compelling landing page explains the benefit.
2. User enters a goal and chooses one category: Study, Career, Skill Building, Personal Project, or Other.
3. The app generates exactly seven daily starter actions using transparent, category-based templates.
4. User can edit each task, mark it complete/incomplete, and see progress update.
5. Plans are saved in the same browser so the user can refresh and continue.
6. User can delete a plan and see a thoughtful empty state.

## Why this is useful
It converts a vague goal into a practical first step. It is focused enough to finish and verify in the available hackathon time, but complete enough to demonstrate a real user journey.

## Honesty about AI
The product's plan generation should use clear templates/rules in the MVP. Do not claim that the product uses generative AI unless a real model integration is implemented and disclosed. The Devpost Learn Skill Pack and AI coding agent are used in the development workflow; that is separate from whether the product itself calls an AI model.

## Main demo
Enter “Prepare for my web development interview,” select Career, generate the seven-day plan, edit one action, complete two actions, show progress, refresh to prove persistence, and delete the plan.

## Out of scope
- Login/authentication and password recovery.
- Paid API or external AI model.
- Cloud database or sync between devices.
- Payments, notifications, social features, calendars, and admin portal.
- Medical, legal, financial, or other high-stakes recommendations.
